# W1NS — сайт битмейкера

Портфолио битмейкера W1NS: trap, rage, supertrap, ambient.
Тёмный «замёрзший» дизайн, полноэкранные секции со снапом при скролле, рабочая драм-машина на Web Audio API.

## Стек

- React 18 + Vite
- Чистый CSS (переменные, grid, flex, scroll-snap, backdrop-filter)
- Web Audio API: звуки синтезируются кодом, без библиотек

## Запуск

```bash
npm install
npm run dev      # локальный сервер разработки
npm run build    # сборка в папку dist
```

## Структура

```
src/
  App.jsx              корневой компонент, скролл и активная секция
  styles.css           все стили, цвета в :root
  data/content.js      все тексты и данные (релизы, жанры, контакты)
  audio/engine.js      звук: драм-машина и превью треков
  components/
    Hero.jsx           первый экран: фон, навигация, новый релиз
    About.jsx          обо мне (bento-сетка)
    Albums.jsx         релизы, треклист, превью при наведении
    Sound.jsx          жанры на полосах стекла
    Lab.jsx            драм-машина 4×16
    Footer.jsx         контакты в стиле HUD
public/
  bg/                  фоны hero
  covers/              обложки релизов
```
