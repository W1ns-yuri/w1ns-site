## 2. Проект

- **Репозиторий:** https://github.com/W1ns-yuri/w1ns-site (public, ветка `main`)
- **Хостинг:** Vercel, подключён к репозиторию, деплой на каждый пуш. SPA-роутинг через `vercel.json` (rewrites на `/index.html`).
- **Стек:** React 18 + Vite 5, React Router 6, чистый CSS (переменные, grid, flex, scroll-snap, backdrop-filter), Web Audio API / HTMLAudioElement. Без UI-библиотек и Tailwind.
- **Мобильная версия пока не делается** — сначала утверждаем десктопный дизайн.

### Структура

```
index.html                 шрифты Google: Unbounded, Onest, JetBrains Mono
vercel.json                SPA rewrites
src/
  main.jsx                 BrowserRouter
  App.jsx                  маршруты: / и /escape
  styles.css               стили главной, цвета в :root
  data/content.js          ВСЕ тексты и данные главной (релизы, жанры, контакты, драм-паттерн)
  audio/engine.js          звук: драм-машина (синтез), общий плеер mp3 playFile/stopFile, превью-заглушки
  components/              секции главной: SideNav, Hero, About, Albums, Sound, Lab, Footer
  pages/Home.jsx           главная (скроллер со снапом + 6 секций)
  pages/escape/            страница альбома ESCAPE
    EscapePage.jsx
    scenes.js              сценарий: 5 сцен = 5 битов (текст, теги, субтитры)
    escape.css
public/
  bg/bg10.webp             фон hero
  covers/                  escape.webp, moon.webp, scorpion.webp
  audio/escape/            30-сек превью: creepy-night, running, got-lost, memory, escape (.mp3)
```

Запуск: `npm install` → `npm run dev`. Сборка: `npm run build`.

## 3. Дизайн: «Cold Glass»

- **Настроение:** замёрзший космос, минимализм, лёгкость и «вау». Тёмный синий, местами белый, мягкие размытые градиенты, glassmorphism. Вдохновение — визуал битмейкера **Skypierr** (гранж, ледяной синий, готика, наклейки, штрихкоды) и HUD-интерфейсы.
- **Каждая секция на весь экран**, скролл сам доводится (CSS scroll-snap). Справа фиксированная навигация 01–06 (`mix-blend-mode: difference`).
- **Шрифты:** Unbounded 900 — заголовки и огромный «W1NS»; Onest — текст; JetBrains Mono — подписи, цифры, HUD.
- **Цвета (`:root`):** `--ink #01040B`, `--night #03060D`, `--navy #0A2540`, `--ice #EAF3F6`, `--frost #DCEBF1`, `--glacier #5B9BD5`, `--mint #7DF9D4` (холодный мятный акцент; жёлтый и салатовый **убраны по просьбе Юрия**).
- **Анти-слоп правила:** никаких эмодзи вместо иконок (только SVG), без фиолетовых AI-градиентов, без шаблона «hero + 3 карточки». Перед релизом прогонять через скилл **unslop-ui**.
- Скиллы, которые Юрий поставил: **Impeccable** (основной для дизайна/полировки), **unslop-ui** (финальная проверка), **Taste Skill** (для «вау»-лендингов).

## 4. Главная страница (`/`)

1. **Hero:** фон — размытое фото `bg10` (тёмная синяя «жидкость», blur 24px), медленно «дышит». Сверху: логотип W1NS®, стеклянная капсула-навигация (РЕЛИЗЫ / ОБО МНЕ / ЗВУК / LAB / КОНТАКТЫ), белая кнопка «ОТКРЫТ ДЛЯ КОЛЛАБОВ». Справа виджет ESCAPE (обложка, эквалайзер, Play → `/escape`) и плашки «3 РЕЛИЗА · 11 ТРЕКОВ · 100 СЭМПЛОВ». Внизу огромный белый «W1NS» от левого края.
2. **About (bento-сетка):** «W1NS — битмейкер со стажем» + стили + релизы. **Без истории** (биография будет на отдельной странице позже). Карточки: фото (заглушка), «Мой сетап» (FL Studio, React, JS, Supabase, 808, Serum), «Стили», «Связь».
3. **Albums:** обложки ESCAPE / MOON / SCORPION. Клик → треклист. Наведение на трек → превью (у ESCAPE — настоящие mp3, у остальных — синтез-заглушка). SCORPION — сетка сэмплов (23 плитки + «+77»). У ESCAPE ссылка «ОТКРЫТЬ ФИЛЬМ-АЛЬБОМ →».
4. **Sound:** 6 полос рифлёного стекла = любимые жанры (TRAP, SUPERTRAP, LOVE MUSIC, AMBIENT, DNB, EXPERIMENTAL), наведённая раскрывается.
5. **Lab:** рабочая драм-машина 4×16 (KICK, CLAP, HI-HAT, 808), 150 BPM, звук синтезируется кодом.
6. **Footer (HUD):** бегущая строка жанров, кнопки соцсетей со срезанными углами, радар, «SIGNAL ONLINE», гигантский контурный W1NS.

## 5. Страница ESCAPE (`/escape`) — «фильм в пяти битах»

**Альбом:** W1NS × **CASSETTE** (друг-битмейкер, сделали пополам, но это больше альбом Юрия). Идея — кино битами: слушаешь и видишь историю. Финал открытый, каждый слушатель решает сам.

**Треки и сюжет:**
1. **Creepy_Night** — герой просыпается в ночном лесу, ничего не помнит, вибрирует телефон; в левом ухе морзе «ESCAPE». Таинственная мелодия, драмка входит постепенно, необычные звуки, дрилл-бас с дилеем и ревером, основной бас в духе Zaytoven/Spinz, во второй части дрилл. В конце воют духи.
2. **Running_From_Fear** — авария, сирена; он увидел что-то загадочное и убегает. Тревожная мелодия, дрилл, много партий баса, драмка в конце ускоряется (погоня), падение и отдышка.
3. **Got_Lost** — потерялся, блуждает, вспоминает увиденное. Простая драмка, зажёванные и запитченные звуки.
4. **Memory** — перебор гитары, тёплые воспоминания (любовь? дом? — у каждого своё). Флейта, скрипки в дропе, экспериментальная драмка, **дроп перенесён на второй бар**. Находит одинокий двухэтажный дом, скрип двери, бит обрывается.
5. **Escape** — заходит в дом и понимает, что случилось. Красивая мелодия, дроп уходит в рок, каждый дроп сильнее, в последних двух сильный лид, дающий надежду. Находит картину (= обложка альбома), разбегается и прорывается сквозь неё → птицы, пшеничное поле, снова морзе, потом гром и дождь.

**Как сделана страница:**
- Киношные чёрные полосы сверху/снизу, плёночное зерно, сканлайны, REC-индикатор «СЦЕНА 0X / 05». Вверху просто **ESCAPE**.
- Экраны: Пролог → 5 сцен → Поле → Гроза → Титры.
- **Звучат только биты Юрия** (синтез-звуки убраны по его просьбе). Кнопка «СМОТРЕТЬ ФИЛЬМ» включает звук; **каждая сцена при появлении включает свой бит, по окончании 30-сек превью страница сама листает к следующей сцене**. Внизу плеер: название, прогресс, пауза. Без клика — кнопка «ВКЛЮЧИТЬ ЗВУК» (ограничение браузеров).
- Визуал сцен: светлячки и вибрирующий телефон; мигалки и кардиограмма; плывущее «ГДЕ Я?» и компас; полароиды, струны, схема переноса дропа, открывающаяся дверь; картина-обложка, которая рвётся пополам; поле; дождь и молнии; титры.
- Превью: 30 сек из самой громкой части каждого трека (обычно дроп), фейды, 128 kbps mp3. **Полные треки на сайт не выкладываем.**

## 7.5. Что добавлено в редизайне (ноябрь 2026)

- **Библиотеки:** GSAP (ScrollTrigger, SplitText) и Lenis (плавный скролл). **Scroll-snap на главной убран.**
- **Главная:** интро hero (буквы W1NS выезжают, фон наводит фокус), параллакс от мышки, при скролле буквы разлетаются; секция Albums закрепляется, обложки «раздаются» как карты; у каждой секции своя анимация появления. Всё в `src/animations/homeScroll.js`.
- **Переход между страницами:** чёрные кинополосы, `src/components/PageTransition.jsx` (`TransitionLink` вместо `Link`).
- **Новые страницы:** `/beats` (каталог с настоящими волнами превью, фильтр, плеер, лицензии), `/about` (история листается вбок, блок сотрудничества), `/moon` (6 треков = 6 фаз луны), `/scorpion` (поле из 100 сэмплов). Общие части: `src/components/SiteNav.jsx`, `NextPage.jsx`, `src/hooks/usePageMotion.js`, `src/pages/pages.css`.
- **Данные новых страниц** тоже в `src/data/content.js`: `beats`, `licenses`, `moonTracks`, `bio`, `contacts`.
- **Сайт качает под бит:** кнопка «Включи бит» в hero (и плавающая пилюля `.soundpill`) запускает превью Escape по кругу. Весь звук идёт через общую шину в `src/audio/engine.js` → анализатор; `src/hooks/usePulse.js` каждый кадр пишет громкость баса/середины/верхов в CSS-переменные `--bass`, `--mid`, `--high` на корне главной, а CSS по ним двигает буквы, вспышку, блобы и контур в футере. `src/components/LiveEq.jsx` — эквалайзер, который показывает настоящий спектр.
- **Свой курсор:** `src/components/Cursor.jsx`. Атрибут `data-cursor="ТЕКСТ"` на элементе даёт подпись в курсоре, `data-magnetic` притягивает элемент к мышке.
- **About на главной:** один большой абзац с обложками-ссылками внутри текста, слова «зажигаются» по скроллу, справа портрет со шторкой. **Lab** стал тёмным, клетки светятся мятным. Бегущая строка в футере ускоряется от скорости скролла.
- **Контакты подключены** (`contacts` и `channels` в `content.js`): Telegram и Instagram `@yuri_w1ns`, YouTube `@prodW1ns`, SoundCloud `old-line`, YouTube команды `@oldlinecrew1`. Кнопки «купить/написать» ведут в Telegram с готовым текстом (`orderLink`).
- **Картинки в `public/img/`:** `w1ns-portrait.webp` — фото Юрия (сгенерировано в Gemini, в углу водяной знак, заменить после съёмки). `nebula`, `ice`, `moon`, `studio` — сгенерированные заглушки, заменить на настоящие фото.
- **Правило:** если элемент анимирует GSAP (opacity/transform), не ставь на эти же свойства CSS `transition` — они конфликтуют.
- **Правило 2:** GSAP ставит элементу, который двигает, инлайновые `scale: none; translate: none; rotate: none`. Поэтому CSS-свойство `scale` на таком элементе работать не будет: вешай его на обёртку.
- **Ещё нужно от Юрия:** цены лицензий, BPM и тональности, названия треков MOON, настоящие фото (список кадров отправлен в треде), проверить теги битов на `/beats`.
