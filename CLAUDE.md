# W1NS site — инструкции для ИИ-ассистента

Полный контекст проекта, решения по дизайну и план: `PROJECT_CONTEXT.md`. Прочитай его перед работой.

Коротко:
- React 18 + Vite + React Router, чистый CSS. Без UI-библиотек и Tailwind.
- Тексты и данные главной — только в `src/data/content.js`; сценарий ESCAPE — в `src/pages/escape/scenes.js`.
- Отвечай Юрию на русском, на «ты», просто и без воды; объясняй код так, чтобы джун понял.
- Без эмодзи вместо иконок (только SVG), без жёлтого/салатового и фиолетовых AI-градиентов.
- Мобильную версию пока не делаем.
- `main` деплоится на Vercel автоматически: перед пушем `npm run build` должен проходить.
